# Bluestock Data Analyst Internship (FinTech) — Deliverables

Repository containing completed Week 1 and Week 2 prerequisite assignments and analysis deliverables.

## Week 1: Core Data Analytics
* *Task 1 (Excel / Google Sheets):* Cleaned retail sales dataset (XLOOKUP, INDEX/MATCH), Pivot Tables, KPI cards, and interactive slicers.
* *Task 2 (SQL):* Relational schema and analytical queries (JOIN, GROUP BY, HAVING, subqueries, RANK(), and running totals).
* *Task 3 (Python):* Automated data cleaning, KPI calculations, and Matplotlib charts using Pandas and NumPy.
* *Task 4 (EDA):* Outlier detection (IQR), correlation analysis, monthly revenue trends, and executive EDA summary report.
* *Task 5 (Power BI):* Interactive Business Performance Dashboard with custom DAX measures (SUMX, DISTINCTCOUNT, DIVIDE).
* *Task 6 (Statistics):* Central tendency, standard deviation, conditional probability, and simple linear regression modeling.

## Week 2: FinTech Domain & Software Fundamentals
* *Task 1 (Stock Market & Financial Analysis):* One-page summary of Indian stock market fundamentals (NSE/BSE, Nifty/Sensex, valuation ratios) and FY 2025–26 financial statement analysis of *TCS*.
* *Task 2 (REST APIs & JSON):* Tested public exchange-rate APIs in *Bruno* and automated JSON-to-CSV extraction in Python.
